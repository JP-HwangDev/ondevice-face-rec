# 프로젝트 목표

## 핵심 목적
**사내 그룹웨어 출석체크 단순화**

## 주요 기능

### 1. 실시간 얼굴 인식 및 AR UI
- 전면 카메라로 실시간 얼굴 감지
- 카메라 화면에 포착시 밑에 제일 유사도 높은 3명의 사원 이름 표시
- **사용자 액션**: 자신의 이름이 뜬 박스를 터치하면 그룹웨어 로그인 승인

### 2. 온디바이스 처리
- iOS/Android 디바이스에서 모든 인식 처리
- 서버 전송 없이 로컬에서 얼굴 특징 추출 및 비교
- 개인정보 보호 강화

### 3. 위조 방지
- TrueDepth 카메라를 활용한 평면 사진 감지
- 실제 입체 얼굴과 사진 구분

## 플랫폼
- **타겟**: iOS 17.0+
- **언어**: Swift 5.x+
- **프레임워크**: SwiftUI, AVFoundation, Vision, Core ML

## 사용 시나리오
1. 사용자가 앱 실행
2. 카메라 화면 표시
3. 얼굴 자동 감지 → 제일 유사도 높은 3명의 사원 이름 표시
4. 본인 이름 박스 터치
5. 그룹웨어 출석 체크 완료
